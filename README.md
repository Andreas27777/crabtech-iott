# 🦀 CrabTech IoT - Smart Mud Crab Aquaculture



## 📌 Tentang Proyek
**CrabTech IoT** adalah solusi *Smart Farming* berbasis Internet of Things (IoT) yang dirancang khusus untuk budidaya kepiting bakau (*Mud Crab*) dalam sistem apartemen vertikal. Proyek ini lahir sebagai respons atas tingginya angka kematian kepiting di Batam yang mencapai 45-60% akibat kualitas air yang tidak terpantau.

Dengan sistem monitoring real-time dan otomatisasi filtrasi, CrabTech IoT bertujuan menekan angka mortalitas hingga **70%** dan meningkatkan efisiensi operasional bagi pembudidaya.

## 🚀 Fitur Utama
- **Monitoring Real-Time 24/7:** Pemantauan parameter pH dan suhu air secara terus-menerus melalui sensor presisi.
- **Sistem Notifikasi Dini:** Peringatan otomatis via WhatsApp/Dashboard jika kualitas air berada di luar ambang batas aman.
- **Otomatisasi SLO & RAS:** Kendali otomatis sistem *Solid Lift Overflow* dan *Recirculating Aquaculture System* untuk menjaga kejernihan air dan menghemat listrik hingga 35%.
- **Dashboard Futuristik:** Antarmuka pengguna dengan estetika *Cyberpunk* yang responsif, dibangun menggunakan Tailwind CSS.

## 🛠️ Spesifikasi Teknologi
### Software
- **Framework:** Laravel 11
- **Frontend:** Tailwind CSS (Cyberpunk Palette)
- **Database:** MySQL via SQLyog
- **Protokol:** MQTT / HTTP API untuk komunikasi data sensor

### Hardware
- **Microcontroller:** ESP32
- **Sensor pH:** E-201-C
- **Sensor Suhu:** DS18B20 Waterproof
